    💡 首次连接？点此查看建表 SQL 步骤
    到 Supabase 后台 → SQL Editor → New query，粘贴下面这段 → Run： 
    create table if not exists public.yi_sync (
  key text primary key,
  value jsonb not null,
  updated_at timestamptz default now()
);
alter table public.yi_sync enable row level security;
create policy "anon_all" on public.yi_sync for all to anon
  using (true) with check (true);
    建表完成后，回到这里再点一次「保存并连接」即可。所有本地数据会自动推上云端 ✅
